# MoscowRealtime

Информационный сайт ООО «Москоу Риалтайм» на React, TypeScript и Vite.

## Запуск

Требуется Node.js 20 или новее.

```sh
npm install
npm run dev
```

Vite выведет локальный адрес для просмотра. Для production-сборки используйте `npm run build`, для локального просмотра готовой сборки — `npm run preview`.

## Страницы

- `/` — главная
- `/about` — о компании
- `/product` — концепция продукта
- `/team` — учредители и организационная модель
- `/documents` — сведения и документы
- `/advantages` — позиционирование и сравнение
- `/partners` — направления сотрудничества
- `/contacts` — доступные способы связи

Описание компании и продукта размещено в соответствующих разделах сайта. Возможности приложения, которые пока не реализованы, обозначены как концептуальные.
